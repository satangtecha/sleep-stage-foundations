# Sleep Stage Foundations

Interactive Thai lesson explaining the project from EEG and sampling through STFT, normalization, CNN, BiGRU, evaluation, and the Baseline/R1/Full-night comparison.

## Open the lesson

Open [`foundations.html`](./foundations.html) in a browser, or enable GitHub Pages for this repository and open the Pages URL.

The attached presentation video is [`SleepStage.mp4`](./SleepStage.mp4).

This repository is an educational presentation copy. It does not contain raw EEG, private Quant OS files, credentials, or training controls.

## Scope note

The reported results are a small research pilot. Baseline is the standard comparison; R1 is post-hoc/transductive and must not be interpreted as an independent online accuracy estimate. The lesson explains these limitations directly.
